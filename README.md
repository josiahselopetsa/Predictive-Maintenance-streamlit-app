About Dataset

This dataset contains 1000 rows of industrial sensor measurements collected over time. It is designed to support predictive maintenance, machine health monitoring, and temporal analytics for industrial systems.

Dataset from kaggle


### Streamlit app
Name: App_Deployment_Maintenance_prediction.py

run as pyscript on Pychar IDE or other IDE

install packages using:
pip install -r requirements.txt

load the .pkl files 

run app on terminal: 
streamlit run App_Deployment_Maintenance_prediction.py
